## 4. Перевод сервиса на базу

Поле `index` и `loadIndexFromDisk()` пока не трогать, чтобы шаг оставался обратимым. Проверить `./mvnw test`
- [x] 4.2 Перевести запись: в `store(MultipartFile)` порядок становится «временный файл → атомарное перемещение → вставка строки»; при неудаче вставки удаляется `{id}.bin`, при неудаче перемещения — временный файл. Запись сайдкара из этого пути убрать. Проверить, что тест на неудачу сохранения метаданных по-прежнему требует пустого каталога после отказа
- [x] 4.3 Удалить индекс в памяти и сканирование каталога: поля `index`, метода `loadIndexFromDisk()` и вызова из `initialize()` больше нет; `initialize()` остаётся только создание базового каталога. Проверить `./mvnw test`
- [x] 4.4 Добавить `LegacyMetadataImporter` в `filestorage.service` как `ApplicationRunner`: сканирует каталог по `*.meta.json`, для каждого сайдкара переносит логику `indexSidecar` без изменений (нечитаемый JSON, несовпадающий id, отсутствующее содержимое → предупреждение в лог и пропуск) и вставляет строку, только если строки с таким id ещё нет. Ничего не удаляет и не переименовывает. По завершении пишет в лог сводку: сколько перенесено и сколько пропущено
- [x] 4.5 Прибрать за переносом: `FileMetadataStore.write` и константы, оставшиеся без ссылок после отказа от записи сайдкара, удалить; `read` оставить — он нужен переносу. Проверить `grep`, что удалённые константы больше нигде не упоминаются. Итог: без ссылок не осталась ни одна — `METADATA_WRITE_FAILED_PREFIX` теперь описывает неудачу вставки строки
